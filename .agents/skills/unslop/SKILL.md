# Unslop UI Guidelines

1. **One bright element**: Each screen has one polished thing that carries the color and the craft (e.g. the professional financial candlestick chart & equity curve). Everything around it is quiet.
2. **Quiet chrome**: Navigation, buttons, cards use tinted neutrals (Zinc 950/900/800) and one accent. Nothing glows, zero arbitrary purple gradients.
3. **Typography & Numbers**: Use clean sans-serif for labels, strict monospace `font-mono` for all numeric values, prices, timestamps, percentages.
4. **Spacing rhythm**: Strict 8pt spacing grid (`gap-4`, `gap-6`, `p-4`, `p-6`). Inner radius = outer radius minus padding.
5. **Icons & Copy**: Use restrained Lucide line icons. No emoji badges, no shouty all-caps or generic marketing filler.
